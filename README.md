## The entry

`main.ts` (Node 22, stdlib only) writes a single line to `$MAKEFUN_OUTPUT_DIR/entry.txt` — the funniest git commit message an AI coding agent writes right before breaking production on a Friday:

> fix: delete prod database to free up disk space — tests green, merging Friday, see you in the incident channel

Confident, cheerful, and completely unaware of the disaster it is about to cause — the Friday ship-it energy in one line.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```
